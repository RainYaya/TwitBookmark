# TwitBookmark

本地个人的书签消化台：把 Twitter 书签、浏览器收藏和 GitHub 星标收进来，按天看一眼，慢慢清理，不让它们在收藏夹里吃灰。

数据只在本机：SQLite（`data/bookmarks.db`）、下载的推文媒体（`data/media/`）、导入文件（`data/imports/`）。服务只监听 `127.0.0.1:4317`。

## 运行

需要 Node 24 和 pnpm。

- 双击 `start.bat`：首次会安装依赖、构建前端，然后打开 <http://localhost:4317>。
- 或者手动：

```bash
pnpm install
pnpm build
pnpm start
```

开发时用 `pnpm dev`（Vite 在 5173，API 代理到 4317）。

## 导入

把导出的文件放进 `data/imports/`，然后在「设置 → 导入」点「扫描 data/imports」，逐行导入；也可以直接选择文件。

- **Twitter**：X 导出的书签 JSON。推文发布时间作为条目日期；媒体和头像都下载到 `data/media/`，不引用外链。
- **浏览器**：Chrome 导出的收藏夹 HTML。重复链接只保留最早加入的一条。
- **GitHub**：先在本机登录 `gh auth login`，然后在设置里点「同步 GitHub 星标」。只新增和更新，**不会取消任何 star**。

重复导入是安全的：已有条目的状态、标签、笔记不会被覆盖。

## 每天怎么用

左侧导航一直在，显示每一类的总条数：

- **视图**：全部收藏、收件箱、稍后、已消化、备查、AI 建议、我的笔记、回收站。
- **来源**：Twitter、浏览器、GitHub。
- **收藏夹**：一个条目只放一个收藏夹，可以新建、改名、删除；「未归类」是还没放进收藏夹的条目。
- **标签**：多标签，按使用量列出前 12 个，可展开全部。

点任意一项就筛选右侧内容；在列表或卡片上按住条目拖到收藏夹、标签或「稍后」等状态上，就能直接归类。

1. **推特流 `/`**：按推文发布时间分组，可按状态、标签和正文搜索筛选；列表一次加载一页，点「加载更多」继续。「快速过一遍」用键盘逐条过：`x` 看过、`c` 已消化、`s` 稍后、`e` 备查、`d` 移除、`u` 撤销。点「详情」看正文、媒体和笔记。底部「回看」每天挑几条旧收藏。
2. **库 `/library`**：三个来源都在这里，按左侧导航或搜索筛选。点一行打开详情，可以写「我的笔记」——这是你自己的话，会以醒目的整块显示在列表和卡片里。开「清理模式」，每屏 10 条，`j/k` 移动、`Space` 选中、`a` 全屏选中，`d` 移入回收站，或用 `s/e/c` 改状态；状态、标签和删除都能用 `u` 撤销（一次批量算一步）。
3. **回收站**：库页面访问 `/library?deleted=1`，可以逐条恢复；打开「批量选择」后 `Space` 多选、`r` 批量恢复。不自动清空。

四个固定状态：收件箱、稍后、已消化、备查。「看过」是独立勾选。

## 键位

| 键 | 作用 |
| --- | --- |
| `?` | 键位帮助 |
| `/` | 搜索 |
| `g t` / `g l` / `g s` | 推特流 / 库 / 设置 |
| `j` / `k` | 下一条 / 上一条 |
| `x` | 勾选看过（库里是多选） |
| `c` / `s` / `e` | 已消化 / 稍后 / 备查 |
| `d` | 移除（可撤销） |
| `t` | 打标签 |
| `o` / `Enter` | 打开原链接 |
| `u` | 撤销上一步 |
| `Esc` | 关闭弹层 / 退出模式 |

## AI 分类（可选）

使用本地 LM Studio 的 OpenAI 兼容接口，默认 `http://localhost:1234/v1`。

1. 在 LM Studio 里加载模型并启动本地服务。
2. 设置里选模型、保存。
3. 「生成标签提案」：按来源比例最多抽取 150 条样本（GitHub 带 description/language/topics，浏览器带域名），生成 10–15 个主题标签；删改后「确认标签」。
4. 「开始分类」：分类时会先读取正文——GitHub 项通过本机已登录的 `gh` 取 README，浏览器收藏直接抓一次网页正文（GBK/UTF-8 都处理，失败的用标题和域名兜底）；然后按内容长度分批（默认最多 12 条、约 7000 字符），生成 1–3 个标签和一句「它是做什么的」说明，只写 AI 建议字段，不碰你手写的标签和笔记。
5. 现有标签都不匹配的条目不硬塞：保持未分类，由模型给出建议的新标签名；任务结束后设置页会显示「未归类 N 条 · 新增 N 个标签」，新标签已放进标签体系提案，确认后再点一次「开始分类」，只补这些未归类的条目。
6. 建议以「AI 建议」显示在推特流和库里：可以逐条接受，也可以点「接受当前筛选建议」一次接受当前筛选结果；不想要就忽略，原条目不受影响。
7. 已有标签可以在设置里改名或删除。

分类任务在设置页显示进度，可暂停和继续；重启后未完成的任务会停在暂停状态，点「继续」接着跑。

## 开发

```bash
pnpm test        # Vitest：服务端 + 组件
pnpm test:e2e    # Playwright：清理模式与快速过一遍的键盘冒烟
pnpm typecheck
pnpm build
```

导入的文件一律当作数据解析，不执行其中任何内容。
