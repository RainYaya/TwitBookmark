# TwitBookmark

本地个人的书签消化台：把 Twitter 书签、浏览器收藏和 GitHub 星标收进来，按天看一眼，慢慢清理，不让它们在收藏夹里吃灰。

数据只在本机：SQLite（`data/bookmarks.db`）、下载的推文媒体（`data/media/`）、导入文件（`data/imports/`）。服务只监听 `127.0.0.1:4317`。

## 运行

需要 Node 24 和 pnpm。

- 双击 `start.bat`：首次会安装依赖、构建前端，然后打开 <http://localhost:4317>。
- 或者手动：

```bash
pnpm install
pnpm build
pnpm start
```

开发时用 `pnpm dev`（Vite 在 5173，API 代理到 4317）。

## 导入

把导出的文件放进 `data/imports/`，然后在「设置 → 导入」点「扫描 data/imports」，逐行导入；也可以直接选择文件。

- **Twitter**：X 导出的书签 JSON。推文发布时间作为条目日期；媒体和头像都下载到 `data/media/`，不引用外链。
- **浏览器**：Chrome 导出的收藏夹 HTML。重复链接只保留最早加入的一条。
- **GitHub**：先在本机登录 `gh auth login`，然后在设置里点「同步 GitHub 星标」。只新增和更新，**不会取消任何 star**。

重复导入是安全的：已有条目的状态、标签、摘要不会被覆盖。

## 每天怎么用

1. **推特流 `/`**：按推文发布时间分组，可按状态、标签和正文搜索筛选；列表一次加载一页，点「加载更多」继续。「快速过一遍」用键盘逐条过：`x` 看过、`c` 已消化、`s` 稍后、`e` 备查、`d` 移除、`u` 撤销。点「详情」看正文、媒体和摘要，摘要可以直接编辑保存。底部「回看」每天挑几条旧收藏。
2. **库 `/library`**：浏览器收藏和 GitHub 星标。开「清理模式」，每屏 10 条，`j/k` 移动、`Space` 选中、`a` 全屏选中，`d` 移入回收站，或用 `s/e/c` 改状态；状态、标签和删除都能用 `u` 撤销（一次批量算一步）。
3. **回收站**：库页面访问 `/library?deleted=1`，可以逐条恢复；打开「批量选择」后 `Space` 多选、`r` 批量恢复。不自动清空。

四个固定状态：收件箱、稍后、已消化、备查。「看过」是独立勾选。

## 键位

| 键 | 作用 |
| --- | --- |
| `?` | 键位帮助 |
| `/` | 搜索 |
| `g t` / `g l` / `g s` | 推特流 / 库 / 设置 |
| `j` / `k` | 下一条 / 上一条 |
| `x` | 勾选看过（库里是多选） |
| `c` / `s` / `e` | 已消化 / 稍后 / 备查 |
| `d` | 移除（可撤销） |
| `t` | 打标签 |
| `o` / `Enter` | 打开原链接 |
| `u` | 撤销上一步 |
| `Esc` | 关闭弹层 / 退出模式 |

## AI 分类（可选）

使用本地 LM Studio 的 OpenAI 兼容接口，默认 `http://localhost:1234/v1`。

1. 在 LM Studio 里加载模型并启动本地服务。
2. 设置里选模型、保存。
3. 「生成标签提案」→ 删改 → 「确认标签」。
4. 「开始分类」：每批 30 条，生成 1–3 个标签和一句摘要，只写 AI 建议字段，不碰你手写的标签和摘要。
5. 建议以「AI 建议」显示在推特流和库里：可以逐条接受，也可以点「接受当前筛选建议」一次接受当前筛选结果；不想要就忽略，原条目不受影响。
6. 已有标签可以在设置里改名或删除。

分类任务在设置页显示进度，可暂停和继续；重启后未完成的任务会停在暂停状态，点「继续」接着跑。

## 开发

```bash
pnpm test        # Vitest：服务端 + 组件
pnpm test:e2e    # Playwright：清理模式与快速过一遍的键盘冒烟
pnpm typecheck
pnpm build
```

导入的文件一律当作数据解析，不执行其中任何内容。
